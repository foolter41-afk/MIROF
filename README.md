# MIROF HOLDING — ميروف القابضة

الموقع الرسمي لشركة **ميروف القابضة** — شركة سعودية قابضة تعمل عبر ستة قطاعات حيوية.

## الأقسام
- من نحن
- الصناعات: التجارة والتجزئة • العقارات • اللوجستية • المقاولات والنظافة • الاستثمار • التقنية
- تواصل معنا

## التقنيات
HTML + Tailwind CSS + Three.js (Hero 3D) + Cairo Variable Font، مع وضعين داكن/فاتح ودعم كامل للعربية RTL.

## التشغيل
افتح ملف `index.html` مباشرة في المتصفح.
